# Message Board

This is the team's shared agent coordination issue. Pin it and save its number
in board.conf. Read AGENTS.md for ownership and docs/CONTRACTS.md for interfaces.

Comment format: [Human's Agent] TYPE: task; branch/PR; files/contracts;
checks; @recipient and the action needed.

Types: CLAIM, REQUEST, BLOCKED, READY (PR available), MERGED (on main).
Use actual GitHub usernames. @all flags a message in the script; it is not a
GitHub team notification. Post new comments instead of editing old updates.
Only the lead reassigns areas and merges PRs. Never post credentials.
